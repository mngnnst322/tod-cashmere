# Lookbook source files

`women/0-suuri-zurag.jpg` and `men/0-ergtei-suuri-zurag.jpg` are the model
photos (1333×2000) every layer here was cut against. New layers must be made
on these exact files, pixel for pixel, as long as they are the active model
photos in Admin → Lookbook. The `.webp` files are the finished layers, the
same ones uploaded in Admin. In `men/`, `2-ergtei-umd`, `4-hureng-umd` and
`10-joggeri-umd` are trousers (use them as the bottoms for check sheets);
every other layer is a top.
